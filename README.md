# FoodHealth AI

## Кратко о проекте

**FoodHealth AI** — это MVP-сервис, который помогает оценить блюдо по фотографии. Пользователь загружает фото еды, система пытается определить, что это за блюдо, показывает несколько вариантов и после выбора даёт примерную оценку полезности через Nutri-Score.

Мы сделали этот проект как учебный стартап в рамках групповой работы по глубокому обучению. Основная идея — упростить анализ питания: не заставлять пользователя вручную искать блюдо, вводить калории и нутриенты, а дать быстрый и понятный результат по фото.

## Проблема

Многие люди хотят питаться более осознанно, но на практике это не всегда удобно. Чтобы следить за рационом, обычно нужно искать блюдо в приложении, указывать порцию, проверять калории, белки, жиры, углеводы и другие показатели. Это занимает время и быстро надоедает. Особенно если человек ест в кафе, столовой или заказывает доставку, потому что в таких случаях он часто не знает точный состав блюда.

Из-за этого многие бросают приложения для контроля питания. Не потому что им неинтересно здоровье, а потому что сам процесс слишком долгий и требует много ручного ввода. В противном случае люди тратят достаточно много времени на расчет и начинают загонять себя в рамки привыного рациона (что невыгодно для ресторанов/кафе с точки зрения появления новых блюд и их продажи).

**FoodHealth AI** пытается решить именно эту проблему. Пользователь просто загружает фото блюда, а система помогает получить базовую оценку без лишних действий.

## Целевая аудитория

Наш проект может быть полезен людям, которые хотят опрозрачить своё питание, но не хотят каждый день подробно считать калории и нутриенты. Это могут быть студенты, офисные сотрудники, занятые люди, которые часто едят вне дома или пользуются доставкой.

Дополнительная ЦА — люди, которые только начинают следить за питанием. Им может быть сложно разбираться в составах, нутриентах и разных показателях, поэтому им нужен простой инструмент, который объясняет результат понятным языком.

Также сервис может быть интересен фитнес-тренерам, нутрициологам и wellness-командам. Такой инструмент можно использовать как быстрый способ фиксировать питание клиентов и обсуждать пищевые привычки без сложных таблиц.

Ну и нельзя не упомянуть полезность данного функционала может применяться в кафе/ресторанах, чтобы сделать прозрачнее выбор блюд не просто по виду, но и по составу и общему вердикту для человека, чтобы успокоить его внутреннее состояние неопределенности. Это вторичная ЦА, если рассматривать данный продукт с точки зрения B2B сегмента.

## Бизнес-ценность

Главная ценность FoodHealth AI в том, что он делает анализ питания проще. Пользователю не нужно вручную заполнять длинные формы — достаточно загрузить фото и получить примерную оценку. Для бизнеса такой проект может быть полезен как отдельный продукт или как функция внутри уже существующего сервиса. Например, его можно встроить в приложение для питания, фитнеса, доставки еды или корпоративного здоровья сотрудников.

Проект можно развивать в нескольких направлениях: сделать личный дневник питания, добавить историю блюд, подключить персональные рекомендации или предложить API для других сервисов.

Главная бизнес-идея проекта простая: если убрать лишний ручной ввод, людям будет проще регулярно следить за питанием.

## Возможные заказчики

#### B2C

- Проект может быть интересен приложениям для питания и здоровья. Для них это способ сделать сервис удобнее: пользователь не вводит всё вручную, а получает результат по фотографии.


#### B2B

- Фитнес-клубы и онлайн-тренеры тоже могут использовать такую механику. Им важно, чтобы клиенты проще отслеживали питание и не бросали это через несколько дней.

- Сервисы доставки еды и кафе могут использовать похожую технологию, чтобы показывать клиентам более понятную оценку блюд. Это может помочь людям выбирать еду не только по вкусу и цене, но и по составу.

- Корпоративные wellness-программы могут использовать проект как простой инструмент для сотрудников. Например, компания может предложить сервис, который помогает людям внимательнее относиться к питанию без сложной медицинской части.

## Как работает решение

Внутри проекта используются две модели.

Первая модель — **CNN**. Она получает на вход фотографию блюда и определяет top-3 наиболее вероятных варианта. Например, если пользователь загрузил фото пиццы, модель может предложить такие варианты:

- pizza — 0.74
- lasagna — 0.12
- hamburger — 0.08

Вторая модель — **MLP**. Она работает уже не с картинкой, а с табличными данными о нутриентах: калории, жиры, сахар, белки, соль и другие признаки. На основе этих данных модель предсказывает Nutri-Score от `a` до `e`.

Общая логика MVP выглядит так:


фото блюда -> распознавание блюда -> выбор класса -> нутриенты -> Nutri-Score -> рекомендация


В текущей версии пользователь может подтвердить правильный класс блюда из top-3 вариантов. После этого система берёт типичный нутриентный профиль для выбранного блюда и передаёт его в MLP-модель.

## Основные функции

В MVP уже можно:

* загрузить фотографию блюда;
* получить top-3 предсказания модели;
* выбрать подходящий класс блюда;
* увидеть примерный нутриентный профиль;
* получить Nutri-Score;
* посмотреть вероятность того, что блюдо относится к более полезным классам `a` или `b`;
* получить короткую рекомендацию.

С технической стороны в проекте есть CNN-модель для изображений, MLP-модель для Nutri-Score, общий inference pipeline и Streamlit-приложение для демонстрации.

## Планы развития

В будущем мы хотим улучшить модель распознавания блюд и добавить больше классов еды, чтобы сервис лучше работал на реальных фотографиях пользователей. Ещё важный шаг — научиться оценивать размер порции. Сейчас система использует нутриенты на 100 грамм, но для более точной рекомендации нужно понимать, сколько еды на тарелке. Также можно добавить распознавание ингредиентов. Например, не просто определять “салат”, а понимать, что в нём есть курица, сыр, соус или другие добавки. В продуктовой части можно сделать личный дневник питания, где пользователь будет видеть историю своих блюд и общую динамику. В более развитой версии сервис сможет давать персональные рекомендации и подсказывать, какие продукты стоит добавить или сократить.
